# SeanTheAtom on GitHub Pages

This folder contains the static site files ready to publish with GitHub Pages.

## Publish the site

1. Create a **public** repository on GitHub.
2. Upload the contents of this folder directly to the repository root. Keep the filenames unchanged; `index.html` must be at the root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select the `main` branch and `/(root)`, then save.
5. After GitHub finishes deploying, open the Pages URL shown in the same settings page and share it with students.

The feedback box currently saves each visitor's note only in that visitor's browser. It does not send or collect feedback centrally.
